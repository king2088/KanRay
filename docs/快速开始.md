# 快速开始

5 分钟从零启动系统并创建第一个看板。本系统是**前后端分离**的低代码看板平台，支持两种启动方式：Docker 一键部署（推荐）或源码运行。

## 一、选择启动方式

| 方式 | 适合场景 | 依赖 |
|------|---------|------|
| **Docker 一键部署**（推荐） | 快速体验、生产部署 | Docker + Docker Compose v2 |
| **源码运行** | 二次开发、调试代码 | Node.js ≥18、npm |

## 二、Docker 一键部署

### 前置要求

- Docker Engine（≥ 24）+ Docker Compose v2，命令 `docker compose version` 可用

### 启动

```bash
cd deploy
./deploy.sh          # 首次自动生成 .env（含随机密钥），构建并启动三容器
```

首次执行会自动：
1. 从 `.env.example` 生成 `deploy/.env`，并注入随机 `JWT_SECRET` / `DATASOURCE_SECRET` / `POSTGRES_PASSWORD`
2. 构建并启动 `postgres`（元数据库）+ `backend` + `frontend`(nginx) 三个容器
3. 后端首次启动自动幂等建表并创建种子管理员

启动完成后控制台会打印访问地址：

```
[deploy] 访问地址：http://localhost:8080
[deploy] Swagger 文档：http://localhost:8080/api/open/docs
[deploy] 初始管理员：admin@kanban.local / admin123（请尽快改密）
```

### 验证启动成功

浏览器打开 http://localhost:8080 ，看到登录页即成功。

![登录页](images/01-login.png)

> 修改端口：编辑 `deploy/.env` 中 `KANBAN_PORT=8080` 后重启 `./deploy.sh down && ./deploy.sh up`。
> 其他常用命令见 [部署运维手册](05-部署运维手册.md)。

## 三、源码运行（开发模式）

需要 Node.js ≥ 18（后端用 ExpressJS 5，前端用 Vite）。

### 1. 启动后端（端口 3001）

```bash
cd backend
npm install
npm run dev          # 或 npm start
```

首次启动自动创建 `backend/data/kanban.db`（SQLite 元数据库）并完成建表、种子数据。

### 2. 启动前端（端口 5173）

```bash
cd front-end
npm install
npm run dev
```

浏览器访问 http://localhost:5173 ，Vite 已把 `/api` 代理到后端。

## 四、首次登录

使用种子管理员账号登录：

```
邮箱：admin@kanban.local
密码：admin123
```

> 生产环境部署后**必须**立即修改初始密码与密钥，详见 [部署运维手册](05-部署运维手册.md)。

登录后进入**数据集**页面 → 下一步创建你的第一个看板。

## 五、3 分钟创建第一个看板

### 第 1 步：上传数据

1. 左侧菜单点击 **数据集**，进入数据集列表页
2. 点击右上角「**上传数据**」按钮（数据源页也可通过「新建数据源 → 上传 Excel / CSV 文件」进入）
3. 选择一个 Excel（.xlsx/.xls）或 CSV 文件（≤20MB、≤20 万行），第一行作为列名
4. 系统自动识别字段类型并预览前 50 行，可手动校正类型（文本/整数/小数/日期/布尔）
5. 点击「创建数据集」，数据集创建完成

> 菜单结构：左侧为 数据源 / 数据集 / 图表中心 / 看板中心 / 系统管理 五个一级菜单；「上传数据」「新建图表」等操作按钮在各页面右上角。

### 第 2 步：新建图表

1. 进入 **图表中心**，点击「新建图表」
2. 选择刚才上传的数据集
3. 选择图表类型（柱状 / 折线 / 饼图 / 表格 / 数值统计卡等）
4. 把字段拖入「维度」和「指标」（例如：`日期`→维度，`金额`→指标，聚合选求和）
5. 右侧实时预览效果，满意后保存

### 第 3 步：搭看板

1. 进入 **看板中心**，输入名称新建看板
2. 点击「编辑看板」
3. 从上方图表库把已保存的图表拖入看板
4. 布局自动 flow-grid 排布，可继续拖入更多图表
5. 保存并退出编辑，点击看板进入预览

### 第 4 步：筛选联动（可选）

1. 在编辑模式下给看板添加**筛选组件**（选择数据源 + 字段）
2. 预览时切换筛选值，**所有同数据源图表自动联动刷新**
